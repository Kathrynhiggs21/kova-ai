# V8 Paid-Render Data Gate

Mock mode may be used to inspect layout and packaging. Gemini mode is stricter.

A biological front is blocked from paid generation when any required canonical field is missing: ID, category, subject, scientific name, lifespan, region, class, status, fun fact, pop color, title material, or habitat background.

Utility fronts and category backs use card-type-specific required fields. The workflow lists blocked IDs and reasons before any Gemini call.
